# Миграция БД

Перенос данных MongoDB между разными операционными системами (например, с Ubuntu на Windows или с CentOS на macOS) — стандартная задача. Поскольку MongoDB хранит данные в бинарном формате, который зависит от архитектуры и версии, прямое копирование папок с данными (/data/db) часто приводит к ошибкам.
Самый надежный и универсальный способ — использование утилит mongodump и mongorestore. Они создают логическую резервную копию (BSON-файлы), которая полностью кроссплатформенна.
Ниже подробный пошаговый пример.

# 📋 Предварительные требования
1. **Версии MongoDB:** Желательно, чтобы версия на целевой машине была такой же или новее, чем на исходной. Перенос с новой версии на старую может вызвать ошибки совместимости.
2. **Доступ:** У вас должен быть доступ к терминалу/консоли обеих машин.
3. **Место на диске:** На исходной машине нужно место для временного архива дампа.

# 🚀 Способ 1: Классический (через промежуточный файл)
Подходит, если машины не видят друг друга по сети или вы хотите сохранить бэкап «на всякий случай».
## Шаг 1. Создание дампа на исходной ОС (Source)
Откройте терминал на машине, где сейчас находится база данных.
1. Создайте папку для дампа:
````
mkdir ~/mongo_backup
````
2. Выполните дамп всей базы данных (или конкретной):
````
# Дамп всех баз данных
mongodump --out ~/mongo_backup

# ИЛИ дамп конкретной базы (рекомендуется, если не нужно всё)
mongodump --db my_database --out ~/mongo_backup
````

Если включена авторизация, добавьте флаги: 
````
--username admin --password secret --authenticationDatabase admin
````

Результат: В папке ~/mongo_backup появятся подпапки с именами ваших баз данных, а внутри — файлы .bson (данные) и .metadata.json (структура индексов).

## Шаг 2. Передача файлов на целевую ОС (Target)
Используйте любой удобный способ передачи файлов:
SCP/SFTP (Linux/Mac → Linux/Mac/Windows):
````
scp -r ~/mongo_backup user@target_ip:/home/user/
````

## Шаг 3. Восстановление на целевой ОС
Откройте терминал на новой машине.
1. Убедитесь, что MongoDB запущена:
````
# Linux
sudo systemctl status mongod

# Windows (PowerShell)
Get-Service MongoDB
# Если не запущена: Start-Service MongoDB
````

2. Выполните восстановление:
````
# Путь к папке, куда вы скопировали backup
mongorestore --dir /path/to/mongo_backup
````

Если нужно восстановить только одну базу в базу с другим именем:
````
mongorestore --db new_db_name --nsFrom "old_db_name.*" --nsTo "new_db_name.*" /path/to/mongo_backup/old_db_name
````
